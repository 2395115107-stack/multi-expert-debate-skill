# Multi Expert Debate Skill

This repository contains a Claude/Codex skill for running structured multi-expert debates.

## Files

- `SKILL.md`: workflow instructions for triage, expert selection, debate rounds, and synthesis.
- `REFERENCE.md`: role pool reference used when selecting expert perspectives.

## Usage

Install or copy these files into a compatible skills directory, then invoke the skill for multi-perspective analysis, expert debate, or stress-testing decisions from several professional angles.
